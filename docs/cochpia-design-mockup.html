设计说明

· 质感：暗色玻璃拟态（毛玻璃 + 半透明 + 细描边 + 柔和阴影），香槟青绿点缀。
· 双端：移动端底部标签栏 + 底部抽屉；桌面端左侧图标导航 + 可拖拽浮动窗口。
· 聊天界面严格仿照 QQ/Line/微信：左对方右自己气泡、头像+名字、居中时间分隔、连续消息头像隐藏、底部输入栏（附件/语音/文本框/发送圆钮）。
· Cochpia 特有叠加层：频道栏（频道/搜索/模式切换）、工具日志折叠卡、🚀 派发任务卡。
· Agent 资料页仿 Line/QQ 个人资料页：顶部 banner + 大头像叠边 + 信息列表 + 关系设定（置顶/免打扰/标签）+ 底部操作按钮。
