# Cochpia 前端设计规格书（供生图 AI 生成设计稿）

> 用途：描述 Cochpia 全部页面、组件、交互方式及后端联系，供生图 AI 生成 UI 设计稿。
> 风格基调：暗色玻璃拟态（Glassmorphism）+ 香槟金/粉樱点缀 + 柔和毛玻璃。

---

## 一、应用身份与设计语言

- **产品名**：Cochpia（AI 陪伴 / 多 Agent 工作台）
- **定位**：一个「共同经历 + 记忆」的 AI 陪伴应用，同时内建多 Agent 协作工作台。
- **配色**（暗色主题）：
  - 画布底色：`#0b121a`（深蓝黑）
  - 面板：`#101b26` / `#172533`（半透明玻璃层）
  - 主强调色：`#8cc9bd`（香槟青绿）
  - 辅助：`#e5bb83`（暖金）、`#ed8c83`（珊瑚红，用于危险操作）
  - 文字：`#f3f7fb`（强）/ `#b6c4d0`（正文）/ `#718496`（弱）
- **质感**：毛玻璃（backdrop-blur）、半透明面板、圆角 6~24px、柔和阴影、极光背景漂移粒子。
- **字体**：中文用系统字体；标题用衬线/手写体（如 Bickham Script）强调「Cochpia」品牌字。

## 二点五、响应式双端布局（桌面端 vs 移动端）

同一套应用，两种形态：

| 元素 | 桌面端（≥760px） | 移动端（≤620px） |
|------|------------------|------------------|
| 导航 | 左侧竖排图标栏（宽约 112px，图标圆钮+文字，垂直排列） | 底部横排标签栏（图标在上、9px 文字在下，均分宽度） |
| 设置/Music 窗口 | 可拖拽浮动窗口（带标题栏 + 最小化/最大化/关闭三键，玻璃质感） | 底部抽屉（贴底、圆角、上方留出底部导航） |
| Agent 角色卡 | 多列网格（每张约 200px 宽） | 单列，通栏 |
| 工作区集成卡 | 4 列网格 | 单列 |
| 聊天区 | 居中限宽（约 800px），带左右留白 | 通栏全宽 |
| 首页内容 | 左移留出导航栏（左侧 136~184px 起） | 全宽，上下留出顶部时钟 + 底部导航 |
| 时钟 | 固定顶部居中 | 固定顶部居中 |
| 交通灯 | 左上角 | 左上角（较小） |

**响应式原则**：桌面端更接近「桌面应用 + 多窗口」；移动端更接近「原生 App + 底部 Tab + 底部抽屉」。

## 三、页面 / 视图清单

### 1. Splash（开屏页）
- 全屏视频背景（樱花/海底场景）+ 半透明渐变遮罩。
- 中央：脉动光球（orb）+ 大号手写体「Cochpia」+ 副标题「Still Blooming」+ 分隔线（✦）+ 底部「轻触进入」。
- 交互：点击任意处 → 进入 Sanctum 首页。
- 后端：无（仅前端）。

### 2. Sanctum（首页）
- **个人档案卡**：头像（圆形，可自定义图片）+ 名字 + 「编辑档案」按钮 + 一句副标题「会从共同经历中逐步形成对你的理解」。
- **双卡片区**：①「新的相遇」（+ 图标，会话数）②「日历」（calendar 图标，日程数）。
- **Agents 区**（标题「Agents」）：
  - 角色卡网格（见「Agent 角色卡」）。
  - 末尾两张虚线卡片：「＋ 新建角色」「👥 发起群聊」。
- **Sessions 区**（标题「Sessions」）：会话列表（标题 + 删除按钮）。
- 后端：`GET /api/sessions`、`GET /api/agents`、`GET /api/profile`、`GET /api/memory/overview`。

### 3. Chat（聊天页，主界面）⭐ 需仿照 QQ / Line / 微信等主流聊天软件

> **重要设计标注**：本页面的布局、气泡、头像、时间戳、输入栏等视觉与交互，**必须参照 QQ / Line / 微信等主流聊天软件的成熟范式**，不要自己发明新形态。

**主流聊天软件的标准三区结构：**

**① 顶部聊天头部（Chat Header）**
- 左侧：返回/头像（对方圆形头像 + 在线状态小点）+ 名字（备注名优先）+ 副标题（个性签名 / 在线状态 / 群成员数）。
- 右侧：「…」更多菜单、语音/视频通话图标（Cochpia 可换成：主题切换、SSE 状态）。
- 群聊时：标题显示群名 + 成员数，右侧有「群信息」入口。

**② 消息区（Message List）**
- **气泡方向**：对方（Agent）靠左、自己（用户）靠右（主流范式）。
- **对方气泡**：浅色/玻璃白底 + 深色文字，圆角「左上小、其余大」；气泡旁显示圆形头像 + 发送者名字（群聊时）。
- **自己气泡**：强调色（香槟青绿）底 + 深色文字，圆角「右上小、其余大」，右侧显示自己的头像。
- **时间戳分隔条**：居中灰字，显示「今天 / 昨天 / X月X日」+ 时分。
- **连续消息**：同一人连续发言时，只显示第一条的头像和名字，后续消息仅气泡（主流软件的紧凑范式）。
- **消息操作**：悬停/长按气泡弹出「复制 / 编辑 / 删除 / 朗读」，小字灰按钮。
- **已读回执**（可选）：对方消息下方可显示「已读」小字。

**③ 底部输入栏（Composer）**
- 左侧一排圆形图标按钮：📎 附件上传、🎤 语音输入（按住说话）、🔊 自动朗读开关。
- 中间：多行文本输入框（占位符「写下此刻想分享的事…」），可自动增高。
- 右侧：圆形发送按钮（↑），输入为空时置灰禁用。
- 底部小字：「Enter 发送 · Shift+Enter 换行」。

**Cochpia 特有叠加层（在标准聊天结构上增加）：**
- **频道栏**：在顶部头部下方一条横栏，含频道标签（可新建 +）+ 搜索框 +「陪伴/工作」模式切换 +（群聊时）「并行/轮流」发言模式按钮。
- **工具日志**：消息流里嵌一个可折叠的「工作状态」卡片（🔧 工具名 + 参数 + 结果）。
- **派发任务卡**：🚀「已派发给 codex/pi」+ 任务描述 + 实时状态轮询。

**后端**：`POST /api/chat/stream`（私聊 SSE）、`POST /api/chat/group`（群聊 SSE）、`POST /api/chat/regenerate`、`DELETE /api/sessions/:id/messages/:id`、`PATCH /api/mode`。

### 4. 共生（LifeGame）
- 玻璃城市垂直切片场景：昼夜渐变天空、城市天际线、像素角色立绘、地点卡片（咖啡馆/家/桥）、需求条（体力/心情/…）、关系值、行动卡片（3 列）、决策卡。
- 底部可展开「生命格日历」（52×7 格点阵，代表人生周数）。
- 后端：`GET /api/life/*`（如实现）、日历本地。

### 5. 工作区（Workbench）
- **页头**：「COCHPIA WORKSPACE / 工作区」+ 右侧「协作开发」主按钮 + 连接就绪计数（x/5）。
- **模型配置面板**：eyebrow「MODEL DIRECTORY」+ 标题「模型配置」+ 状态灯；两个下拉（模型供应商 / 模型）+「测试连接」+「用于当前会话」按钮。
- **集成卡片区**（2~4 列网格）：GitHub / Codex / Pi / Claude / MCP，每张卡有图标、名称、描述、连接状态灯。
- **任务派发区**：目标执行器选择 + 任务描述 textarea +「发送任务」按钮。
- **任务工作流面板**：步骤条（分析→准备→派发→验证）+ 状态徽标 + 操作按钮（开始验证 / 通过 / 打回 / 拒绝 / 导出补丁 / 丢弃）。
- **协作流水线**：填目标 →「协作开发」→ 步骤条展示 plan(pi)→implement(codex)→verify→review 四阶段实时状态。
- 后端：`GET/POST /api/models`、`GET/POST /api/workbench/tasks`、`POST /api/workbench/tasks/:id/verify|review|gate|merge|discard`、`GET/POST /api/workflows`、`POST /api/workflows/:id/run`、`GET /api/workflows/runs/:id`。

## 四、核心功能模块（UI + 交互 + 后端）

### A. Agent 角色卡（首页 Agents 区）
- **视觉**：顶部渐变 banner（56px）+ 圆形头像（44px，叠在 banner 下沿，白描边阴影）+ 名字（首字头像）+ 角色定位副标题 + 模型徽章（胶囊，右上）+ 个性签名一行 + 「说话语气」信息行 + 底部三按钮（发消息 / 编辑 / 删除）。
- **交互**：点头像 → 打开资料页；「发消息」→ 私聊（复用已有会话）；「编辑」→ 打开编辑表单；「删除」→ 确认删除。
- **后端**：`GET /api/agents`、`POST /api/agents`、`PATCH /api/agents/:id`、`DELETE /api/agents/:id`、`POST /api/sessions`（建私聊）。

### B. Agent 编辑表单（弹窗）
- 字段：名字、备注名、头像图片（上传/预览/移除）、角色定位、说话语气、个性签名、人格设定（多行）、记忆备注（多行）、模型下拉（只显示已配置的供应商）。
- 按钮：「创建角色 / 保存角色」。
- 后端：`POST /api/agents` / `PATCH /api/agents/:id`。

### C. Agent 资料页（弹窗，仿 Line/QQ 个人资料页）
- **视觉**：顶部渐变 banner（96px）+ 大头像（72px，圆角描边）+ 名字（置顶 📌 徽标可显示）+「原名」+ 个性签名 + 信息列表（角色定位/关系/说话语气/模型/人格设定/记忆备注）+「关系设定」区（置顶开关、免打扰开关、标签 chips 可增删）+ 底部「发消息」「编辑」。
- **交互**：置顶/免打扰即时切换；标签点「＋添加」输入、点 × 移除。
- **后端**：`PATCH /api/agents/:id`（置顶/免打扰/标签即时乐观更新）。

### D. 私聊（1v1 对话）
- 绑定到某个 Agent 时，标题显示该 Agent 头像首字 + 名字 + 签名；回复以该 Agent 的名字/人格/模型回答。
- 默认私聊 = 与主陪伴者 Cochpia。
- **后端**：`POST /api/chat/stream`（SSE，boundAgent 逻辑）。

### E. 群聊（多 Agent）
- 创建：弹窗选成员（头像首字 + 名字 + 角色）+ 群名 + 简介 → 创建。
- 发言模式：**并行**（各自独立回复）/ **轮流**（后一个能看到前一个的话）。
- 群聊上下文已注入：每个 agent 知道群名、成员列表、自己的身份。
- 消息气泡带发送者名字和头像首字。
- **后端**：`POST /api/sessions`（kind=group + agentIds）、`POST /api/chat/group`（SSE 流式）、`PATCH /api/sessions/:id`（群信息/成员/发言模式）。

### F. 审批弹窗（工具调用审批）
- 风险分级显示：写入/执行/部署。
- 写操作：勾选「本次会话始终允许文件写入」。
- 部署：二次确认（弹窗标题变「二次确认部署操作」）。
- 按钮：「确认执行」「拒绝」；interrupt 时「补充意见并重试」。
- **后端**：`POST /api/chat/approve`（allow/interrupt/deny + acceptForSession）。

### G. 工作区任务派发 + 协作流水线
- 单任务：选执行器（Codex/Pi/Claude）→ 填任务 → 发送 → 沙箱执行 → 验证 → 审查。
- 协作流水线：填目标 →「协作开发」→ 自动展开 pi 规划 → codex 实现 → 验证 → 审查 四阶段，步骤条实时状态轮询。
- **后端**：见工作区 API。

### H. 设置窗口（浮动窗口）
- 左侧/顶部分类导航：外观 / 字体 / 背景 / 声音 / 时间 / 语言 / 工作区 / 无障碍 / 数据。
- 每个分类：色卡、圆角滑杆、透明度滑杆、字体选择、背景图上传、音量、时钟格式、语言、无障碍开关、数据导入导出。
- **后端**：`GET/PATCH /api/preferences`、`POST /api/export`、`POST /api/import`。

### I. 用户档案（弹窗）
- 名字、性别（4 选）、年龄滑杆、头像（emoji 或上传）、纸娃娃立绘组合器。
- **后端**：`GET/PATCH /api/profile`。

### J. 音乐窗口（浮动窗口）
- 音乐桥接：当前曲目、状态、搜索、播放/暂停/下一首/停止、检查环境、刷新、读取上下文。
- **后端**：`/api/music/*`。

## 六、设计稿生成建议（给生图 AI 的提示要点）

### 需要同时出两套尺寸
- **移动端**：390×844 竖屏为主（基准）。
- **桌面端**：1440×900 横屏为主。

### 建议的产出清单（每套各 8 张）
1. Splash 开屏页
2. 首页（Sanctum，含 Agent 角色卡网格）
3. 聊天 - 私聊（单 agent）
4. 聊天 - 群聊（多成员气泡 + 发送者名字）
5. Agent 资料页（仿 Line/QQ 个人资料页）
6. 工作区（Workbench，含协作流水线步骤条）
7. 设置窗口
8. 审批弹窗（风险分级 + 二次确认）

### 统一质感要求
- 暗色玻璃拟态 + 香槟青绿点缀 + 毛玻璃 + 圆角 12-24px。
- 移动端：底部 Tab 导航 + 底部抽屉式弹窗。
- 桌面端：左侧竖排图标导航 + 可拖拽浮动窗口。
- **聊天界面（私聊/群聊）必须仿照 QQ / Line / 微信的主流聊天软件范式**：左对方右自己气泡、头像+名字、居中时间分隔条、连续消息头像隐藏、底部输入栏（附件/语音/文本框/发送圆钮）。
- Agent 资料页重点参考 Line/QQ 个人资料页布局。
- 群聊界面要体现「多成员气泡 + 发送者名字 + 并行/轮流切换」。
- 频道栏、工具日志、派发任务卡是 Cochpia 在标准聊天界面上的「特有叠加层」。
- 桌面端聊天可参考 QQ/Telegram 桌面版：左侧会话列表 + 右侧对话窗口；移动端参考微信/Line 单列全屏。
