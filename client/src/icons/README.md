# Feather icon library

This directory keeps the local Feather SVG backup used by the frontend.

- Source: https://feathericons.com/
- Pinned source release: `v4.29.2`
- Runtime wrapper: `FeatherIcon.jsx`

Keep icon names aligned with the original Feather filenames. UI code should use
`FeatherIcon` for interactive controls so size, stroke width, labels, and color
remain consistent across desktop and mobile layouts.
